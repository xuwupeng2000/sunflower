# 花朵美术方向

- 生长与枯萎最终要求（2026-11-10）：施肥长高通过新增一节独立花茎，不拉长旧花茎或花叶；蝴蝶兰枯萎时花叶形状、大小、颜色保持不变，只弯花梗，让整簇花低头；旋转时植物和花盆作为整体一起转动。

- 向日葵新方向探索（2026-11-10）：用户不喜欢当前向日葵风格，要求重新生成 **3D 插画风格** 图片。先做自然花型、干净哑光材质与柔和光影的预览，减少零碎多面体折面。此轮仅出图，尚未确认新图或替换项目模型。

- 初始姿态（2026-11-10）：初始花图应为正常、紧凑的开花比例，不能预先拉成很高的植株。尤其兰花应缩短裸露花梗，让花簇靠近叶丛上方；后续游戏生长才延长花梗。可长高是模型与动画能力，不代表初始参考图必须很高。

- 兰花形态纠正（2026-11-10）：本项目图中为蝴蝶兰。宽厚、长椭圆带状、全缘钝尖的叶片集中在底部短冠，交互呈两列叶扇；长花梗从底部叶腋抽出，上面只有节与小苞片，不沿梗交错长大叶。此前为游戏生长而添加的兰花梗叶作废。可延长的是裸露花梗段。

- 已获用户确认的视觉参考（2026-11-09）：`assets/concept/flowers/sunflower-orchid-faceted-cel.png`。后续以这张图的植物形体、多面体结构和光影观感为准。

- 用户最新明确（2026-11-09）：花朵采用 **三阶赛璐璐渲染（Cel Shading）**，类似《头文字D》的 3D 做出 2D 动画观感。花型与比例接近真实植物，每种材质以亮部、固有色、暗部三档硬边色块表现体积。避免平滑渐变、手绘笔触、照片写实感，以及过度卡通、玩具或黏土质感。此前手绘插画方向不符合要求。
- 花朵概念图也用于 Tripo 图片生成 3D 模型，绘制时应保持完整轮廓、清晰体积和干净背景。
- 向日葵和兰花都可以长得很高：中间花茎需要能延长。叶片可以沿茎在不同高度交错分布，不应全部集中于底部；在叶片节点之间保留清晰、粗细相对一致的可延长茎段。后续建模把花头、叶片与茎段拆分，便于生长时调整叶片位置。
- 细节密度（2026-11-09）：三阶赛璐璐版本需要进一步简化，减少花盘颗粒、花瓣纹路、叶脉及零碎阴影；优先大块清晰色面和可辨认的花型。
- 最新纠正（2026-11-09，优先于此前“卡通一点”）：用户拒绝幼稚卡通造型。目标是像真实植物一样的比例与结构，用更多多面体表现花瓣折面、叶片弯折和厚度，**仅光影为三层赛璐璐**。避免圆鼓玩具花瓣、粗描边、糖果色和手绘插画感；细节简化指减少纹理噪声，不是把植物形体幼儿化。保留茎上叶片及可延长茎段。
